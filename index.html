ImageHub · 文生图与图片编辑平台

一个页面 + 一套 API，统一调度 5 个开源图像模型：MiniMax H3-Image、Qwen-Image-2.1（原版 / 无限制）、 Z-Image-Turbo、MOSS-Image，外加 Qwen-Image-Edit-2511 做图片编辑。
网页端用于人工对比与调参；程序端直接调 POST /v1/images/generations（OpenAI 兼容）， 未加载的模型自动加载、加载后常驻复用，无需关心底层 ComfyUI 与显存调度。
按需加载请求哪个模型就自动加载哪个，首次约 +20~40 秒
常驻复用加载后不卸载，同模型后续请求只花生成时间
同模型并行 / 跨模型排队生成中的任务不会被打断，换模型等它跑完
OpenAI 兼容 APIPOST /v1/images/generations，可直接用 OpenAI SDK 或任意 HTTP 客户端
网页 + API 双入口网页做对比与编辑；API 给 Dify / 业务系统调用，二者共享同一套模型

API 调用

当前地址 https://192.168.0.70:5569 。外部调用需 API Key（请求体 apikey 或 Authorization: Bearer）； 网页登录会话可直接调用。自签证书：命令行加 --cacert imagehub.crt，或点右上角「证书」下载安装。
下载 API 说明

POST /v1/images/generations

OpenAI 兼容。未加载的模型自动加载，加载后常驻复用；图像与 TTS 不共存，图像请求会先释放 TTS。
curl --cacert imagehub.crt \ -X POST https://192.168.0.70:5569/v1/images/generations \ -H "Content-Type: application/json" \ -d '{"model":"qwen","prompt":"赛博朋克城市夜景","size":"1024x1024","seed":42,"backend":"direct","response_format":"url","apikey":"ih-..."}'
参数类型必填说明
promptstring是提示词
modelstring否qwen（默认）/ h3 / zimage / moss / flux2klein / nemotron / auto
sizestring否宽x高，不传用模型默认；单边上限 2048
seedint否随机种子，默认 42
response_formatstring否url（默认，相对路径）/ b64_json
backendstring否direct（直连 diffusers）/ comfyui；留空用全局设置
only_loadedbool否true 时只用当前已加载模型，不触发切换
apikeystring是API Key；也可用 Authorization: Bearer

响应

{"created":1700000000,
 "data":[{"url":"/image/hub_qwen_ab12cd34.png","revised_prompt":"..."}],
 "model":"qwen","duration_s":10.2,"size":"1024x1024","job_id":"..."}
b64_json 时 data[0].b64_json 是 base64；url 是相对路径，前面拼基础地址即可。

Python（OpenAI SDK）

from openai import OpenAI
import httpx
client = OpenAI(base_url="https://192.168.0.70:5569/v1", api_key="ih-...",
                http_client=httpx.Client(verify="imagehub.crt"))
r = client.images.generate(model="qwen", prompt="水彩橘猫", size="1024x1024",

POST /api/edit

上传图片 + 自然语言指令做编辑。网页登录会话可直接调用；外部建议使用带 Key 的 /v1 接口或携带 Bearer。
curl --cacert imagehub.crt \ -X POST https://192.168.0.70:5569/api/edit \ -H "Content-Type: application/json" \ -d '{"prompt":"把背景换成夜晚的赛博朋克街道","image_b64":"data:image/png;base64,...","seed":7,"steps":20,"apikey":"ih-..."}'
参数类型必填说明
promptstring是编辑指令
image_b64string是图片 base64，可带 data:image/png;base64, 前缀
seedint否默认 42
stepsint否推理步数，默认 20（ComfyUI 路径）

响应

{"status":"ok","image":"hub_edit_ab12cd34.png",
 "url":"/image/hub_edit_ab12cd34.png","duration":36.4,
 "model":"Qwen-Image-Edit-2511"}

POST /api/compare → GET /api/jobs/{job_id}

异步多模型对比：先提交拿 job_id，再轮询任务；每个模型独立落盘，失败不影响其它模型。
curl --cacert imagehub.crt \ -X POST https://192.168.0.70:5569/api/compare \ -H "Content-Type: application/json" \ -d '{"prompt":"赛博朋克城市夜景","models":["qwen","zimage","moss"],"width":1024,"height":1024,"seed":42,"backend":"comfyui"}' # → {"job_id":"ab12cd34"} curl --cacert imagehub.crt https://192.168.0.70:5569/api/jobs/ab12cd34
参数类型必填说明
promptstring是提示词
modelsstring[]是要对比的模型，如 ["qwen","zimage","moss"]
width / heightint否尺寸，默认用各模型默认值
seedint否默认 42
backendstring否comfyui / direct；留空用全局设置

任务响应

{"id":"ab12cd34","status":"done","prompt":"...","models":["qwen","zimage"],
 "results":[{"model":"qwen","status":"ok","image":"...","duration":10.2,"size":"1024x1024","seed":42}]}

POST /v1/audio/speech（OpenAI 兼容）

CustomVoice 预设音色。返回 audio/wav（24kHz 单声道）。TTS 与图像模型不共存，首次加载三个 1.7B 约 4 秒。
curl --cacert imagehub.crt \ -X POST https://192.168.0.70:5569/v1/audio/speech \ -H "Content-Type: application/json" \ -d '{"input":"你好，欢迎使用 ImageHub。","voice":"Vivian","language":"Chinese","response_format":"wav","apikey":"ih-..."}' \ -o out.wav
参数类型必填说明
inputstring是要合成的文本，≤2000 字
voicestring否预设音色，默认 Vivian；另有 Serena / Uncle_Fu / Dylan / Eric / Ryan / Aiden / Ono_Anna / Sohee
languagestring否Auto（默认）/ Chinese / English / Japanese / Korean / German / French / Russian / Portuguese / Spanish / Italian
response_formatstring否只支持 wav
apikeystring是API Key；也可用 Authorization: Bearer

POST /api/tts/speak（声音设计 / 自定义音色）

# 自定义音色（POST 请求体带 apikey，和图像 API 一致）
{"variant":"custom","text":"你好","language":"Chinese","speaker":"Vivian","instruct":"温柔平静","apikey":"ih-..."}

# 声音设计（instruct 必填）
{"variant":"design","text":"你好","language":"Chinese","instruct":"一位年轻女性，温柔、清晰、语速稍慢","apikey":"ih-..."}
参数类型必填说明
variantstring是custom / design
textstring是要合成的文本，≤2000 字
languagestring否默认 Auto
speakerstringcustom 必填预设音色名
instructstringdesign 必填声音描述或语气指令

POST /api/tts/clone（声音克隆，multipart）

curl --cacert imagehub.crt -X POST https://192.168.0.70:5569/api/tts/clone \
  -F "apikey=ih-..." \
  -F "text=你好，这是克隆测试" -F "language=Chinese" \
  -F "ref_text=参考音频里说的内容" -F "ref_audio=@ref.wav" \
  -o clone.wav
参数类型必填说明
ref_audiofile是参考音频，≤60 秒 / ≤20MB，wav/mp3/m4a
textstring是要合成的文本
languagestring否默认 Auto
ref_textstring否参考音频的文字；不填需 x_vector_only_mode=true，克隆质量会下降
x_vector_only_modebool否默认 false；true 时只用说话人向量
所有 TTS 接口返回 audio/wav；成功生成会自动进入 TTS 页的「生成记录」，不写图像图库。

语音记录

TTS 专用语音库，独立于图像历史。鉴权与图像 API 一致：POST 用请求体/表单 apikey，GET 可用 ?apikey=；也支持 Authorization: Bearer，网页会话可直接调用。
# 列表（按时间倒序） curl --cacert imagehub.crt \ "https://192.168.0.70:5569/api/tts/history?limit=10&offset=0&apikey=ih-..." # 播放/下载某条音频 curl --cacert imagehub.crt \ "https://192.168.0.70:5569/api/tts/audio/tts_ab12cd34.wav?apikey=ih-..." -o out.wav # 删除单条 / 批量删除 curl --cacert imagehub.crt -X DELETE \ "https://192.168.0.70:5569/api/tts/history/记录ID?apikey=ih-..." curl --cacert imagehub.crt -X POST \ -H "Content-Type: application/json" \ -d '{"ids":["id1","id2"],"apikey":"ih-..."}' \ https://192.168.0.70:5569/api/tts/history/batch-delete
接口说明
GET /api/tts/history?limit=&offset=返回 {"rows":[...],"total":N,"limit":10,"offset":0}，limit 上限 50
GET /api/tts/audio/{file}返回 audio/wav
DELETE /api/tts/history/{id}删除一条记录和音频文件
POST /api/tts/history/batch-delete请求体 {"ids":[...]}，单次最多 200 条
记录字段：id、created、variant、text、language、speaker、instruct、file、duration（音频时长）、elapsed（生成用时）、size。

鉴权

Key 在「管理 → API Key」创建；管理接口还可用 X-Admin-Token。
# 方式一：请求体（图像/TTS POST 通用）
{"apikey":"ih-..."}

# 方式二：查询参数（TTS GET，如 history/audio）
?apikey=ih-...

# 方式三：Bearer
Authorization: Bearer ih-...

# 方式四：网页登录会话（浏览器自动带 Cookie）

状态码含义
400参数错误（尺寸超限、文本为空、参考音频超长/超大等）
401缺少或无效 API Key / 未登录
404记录或音频不存在
409only_loaded 与当前驻留模型不一致
503模型/TTS 加载中、排队超时或服务未就绪
详细文档：服务器 /opt/vLLM/docs/ImageHub调用说明.md。

浏览器可以直接点「继续访问」，不装也能用；如果要消除警告，或给 curl/脚本调用，按下面安装。 只分发 imagehub.crt，不要分发 .key。
下载 imagehub.crt

Windows

双击证书 → 安装证书 → 本地计算机 → 受信任的根证书颁发机构；或管理员 CMD：
certutil -addstore -f Root imagehub.crt

Ubuntu / Debian

sudo cp imagehub.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates

openEuler / RHEL / CentOS

sudo cp imagehub.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust

macOS

钥匙串访问 → 系统 → 导入 imagehub.crt → 双击 → 始终信任。

Firefox

设置 → 隐私与安全 → 证书 → 查看证书 → 证书颁发机构 → 导入。
