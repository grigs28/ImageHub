ImageHub · 文生图与图片编辑平台

一个页面 + 一套 API，统一调度 5 个开源图像模型：MiniMax H3-Image、Qwen-Image-2.1（原版 / 无限制）、 Z-Image-Turbo、MOSS-Image，外加 Qwen-Image-Edit-2511 做图片编辑。
网页端用于人工对比与调参；程序端直接调 POST /v1/images/generations（OpenAI 兼容）， 未加载的模型自动加载、加载后常驻复用，无需关心底层 ComfyUI 与显存调度。
按需加载请求哪个模型就自动加载哪个，首次约 +20~40 秒
常驻复用加载后不卸载，同模型后续请求只花生成时间
同模型并行 / 跨模型排队生成中的任务不会被打断，换模型等它跑完
OpenAI 兼容 APIPOST /v1/images/generations，可直接用 OpenAI SDK 或任意 HTTP 客户端
网页 + API 双入口网页做对比与编辑；API 给 Dify / 业务系统调用，二者共享同一套模型

选择模型（可多选）· 可单独预热加载

API 调用（OpenAI 兼容）

curl -X POST http://192.168.0.70:5569/v1/images/generations \ -H "Content-Type: application/json" \ -d '{"model":"qwen","prompt":"赛博朋克城市夜景","size":"1024x1024","seed":42,"backend":"direct","response_format":"url"}' # Python (OpenAI SDK) # client = OpenAI(base_url="http://192.168.0.70:5569/v1", api_key="none") # client.images.generate(model="qwen", prompt="水彩橘猫", size="1024x1024", # response_format="b64_json")
可用 model：qwen / zimage / moss（图片编辑走 /api/edit） · 参数：prompt、model、size、response_format（url|b64_json）、seed、backend（comfyui|direct，留空用全局设置） · 详细说明见服务器 /opt/vLLM/docs/ImageHub调用说明.md
